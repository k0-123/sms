# SMS Bridge Application

A local-network SMS bridge connecting desktop applications to Android devices.

## Features
- **Android App**: Embedded WebSocket server with local job queue and SQLite/Room storage.
- **Desktop App**: Python/Tkinter management interface with contact management and campaign engine.
- **Automated Cloud Build**: GitHub Actions workflow automatically compiles Android APKs on push.

## Cloud APK Build
Check the [Actions tab](https://github.com/k0-123/sms/actions) to download the compiled `app-debug-apk` artifact.
